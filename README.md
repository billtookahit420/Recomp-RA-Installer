# Recomp RA Installer

Installs a user's own RetroAchievements configuration (retroachievements.toml) into their recomp game packages so achievements work out of the box.

## Credits

- **RetroAchievements** — the achievement service and community at retroachievements.org.
- The recomp packages this tool serves are built with **Matthew Stanley's (mstan) RetroPortingToolkit** frameworks.
- Your filled retroachievements.toml contains your own login token — it is never bundled or distributed; only the blank example file ships here.
